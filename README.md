# 2G-JONES

## ザ・マスクド・スーツ・クエスト (The Masked Suit Quest)

白いマスク・濃紺スーツ・赤ネクタイの男が、雨上がりの商店街を駆け抜けて会社を目指す、レトロ2D横スクロールアクションゲームです。

**遊び方**: `index.html` をブラウザで開くだけ。外部ファイル・ビルド不要(全アセットはコード内でピクセル生成)。

### 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | ← → または A / D |
| ジャンプ | SPACE / ↑ / W (一回押せばフルジャンプ) |
| リスタート | R |
| ミュート | M |

スマホではタッチ操作ボタンが表示されます。

### マスク・システム

- 最初はマスクを着用している(体力2)
- 敵に当たるとマスクが飛んでいく(体力1)
- **マスクなしの状態でさらに被弾するとゲームオーバー**
- ステージ内の予備マスクで回復できる(取った後も一定時間で再出現)

### 敵とアイテム

- 敵: 浮遊するウイルス粒子 / マスクを忘れて怒っている通行人 / 突進してくる赤いスクーター — すべて踏みつけて倒せる
- アイテム: コイン(スコア) / 予備マスク(回復) / 赤ネクタイ(8秒間無敵)
- ゴール: 商店街の先にある「会社」の入口
